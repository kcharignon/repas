## But

Le modèle `Recipe` porte des **composants** (une autre recette du même compte, un multiplicateur, une position), ils sont stockés dans une table séparée, et `GET /api/v1/recipes/{id}` les rend. Les règles de base (bornes, doublon, soi-même, profondeur 1, même compte, secrète/ordinaire) vivent dans le domaine. **Aucune route d'écriture** (COMP-002), **aucun aplatissement** (COMP-004), **aucune copie** (COMP-003) : ce ticket ne change le comportement de personne tant qu'aucun composant n'existe.

## À livrer

1. **Migration** `Version2026110…` (additive, rejouable, `down` retire les index, la table puis la colonne) : table `recipe_component` (`id VARCHAR(36)` PK, `recipe VARCHAR(36) NOT NULL`, `component VARCHAR(36) NOT NULL`, `multiplier DOUBLE PRECISION NOT NULL`, `position INTEGER NOT NULL DEFAULT 0`), index unique `uniq_recipe_component (recipe, component)`, index `idx_recipe_component_component (component)`, **aucune clé étrangère** ; colonne `recipe.component_count INTEGER NOT NULL DEFAULT 0`. Aucune donnée écrite. Déclarée aussi dans le mapping (`doctrine:schema:validate`). Test `RecipeComponentsMigrationTest` comme `IngredientParentMigrationTest` (mêmes colonnes que le mapping, rejouable, aucune ligne touchée, ancien code compatible, `down`).
2. **Entités Doctrine** : `Infrastructure/Entity/RecipeComponent` ; `Recipe` gagne `componentCount` (jamais écrit par `updateFromModel`, seulement par le dépôt quand le drapeau est vrai, décision 25).
3. **Domaine** :
   - `Repas\Repas\Domain\Model\RecipeComponent` (`final`, `ModelInterface`) : `create`, `load`, `getRecipeId()`, `getComponentId()`, `getMultiplier()`, `getPosition()` ; `MIN_MULTIPLIER = 0.01`, `MAX_MULTIPLIER = 100`, jamais `NaN` ni infini.
   - `Recipe` : `MAX_COMPONENTS = 10`, `private Tab $components` (`Tab<RecipeComponent>`, vide par défaut), `private bool $componentsChanged = false`, `getComponents()`, `hasComponents()`, `componentIds()`, `setComponents(Tab)` (appelle `assertNotFrozen()`, juge le nombre, les doublons, soi-même, les multiplicateurs, pose le drapeau), `areComponentsChanged()` ; `load()` accepte `components` (absent : vide) ; `create()` accepte `?Tab $components`. **Les lignes de `copyFromOriginal` ne changent pas** (COMP-003).
   - `RecipeException` : constantes et fabriques pour `RECIPE_COMPONENT_SELF`, `_DUPLICATE`, `_MULTIPLIER_INVALID`, `_LIMIT_REACHED`, `_CHAIN`, `_OWNERLESS` (422), `RECIPE_EMPTY` (422), `RECIPE_COMPONENT_SECRET`, `RECIPE_SECRET_USED_BY_PUBLIC`, `RECIPE_USED_AS_COMPONENT` (409). Les messages ne se renomment pas.
   - Service de domaine pur `Repas\Repas\Domain\Service\RecipeComponentRules` : `assertCanUse(Recipe $parent, Recipe $component, bool $parentIsUsed)` (même auteur sinon `notFound`, parent non neutre sinon `OWNERLESS`, `CHAIN` dans les deux sens, `COMPONENT_SECRET` pour un parent ordinaire), `assertNotEmpty(Recipe)` (lignes + composants ≥ 1), `assertCanBecomeSecret(bool $usedByOrdinary)`, `assertCanBecomePublic(bool $hasSecretComponent)`. **Les règles se jugent sur l'état final** (décision 8).
4. **Ports** `RecipeRepository` (et `RecipeInMemoryRepository`) : `findByIds(list<string> $ids): array<string, Recipe>` (**en lot** : les recettes, leurs lignes, les ingrédients, unités et types en une lecture chacun quel que soit le nombre d'ids ; les modèles rendus n'ont **pas** de composants ; un id inconnu est absent du résultat) ; `isUsedAsComponent(string $recipeId): bool`, `isUsedByOrdinaryRecipe(string $recipeId): bool` (jointure sur la recette composée `secret = false`), `hasSecretComponent(string $recipeId): bool` (existence, jamais un `COUNT`). `IngredientPostgreSQLRepository::preloadByRecipes(list<string>)` (la version en lot de `preloadByRecipe`, que `findByIds` appelle une fois).
5. **Dépôt** : `convertEntityToModel` lit `component_count` ; **seulement si > 0** il lit les arêtes de la recette dans l'ordre de leur position (`RecipeComponentPostgreSQLRepository`, une requête) ; **`save()` n'écrit les arêtes (suppression des absentes, écriture des autres, positions) et `recipe.component_count` que si `areComponentsChanged()`** ; une arête dont la recette utilisée n'existe plus est tolérée (aucune erreur). `RecipeBuilder::withComponent(Recipe|RecipeBuilder, float $multiplier)`.
6. **Lecture** : `RecipeDTO::$components` (`list<RecipeComponentDTO>`, clé **toujours écrite**, `[]` sans composant) ; `RecipeComponentDTO{recipeId, name, serving, multiplier, secret, convertible, rows: list<RecipeRowDTO>}` (lignes **telles qu'écrites**, jamais multipliées ; `rows` de la recette reste ses seules lignes propres). `RecipePostgreSQLLoader::get` : la sélection de la recette gagne `r.componentCount` ; **si > 0 seulement**, une requête pour les arêtes jointes à la recette utilisée (nom, personnes, secret ; `(c.secret = false OR c.authorId = :userId)`, orphelin ignoré) ; l'instruction des lignes devient `rr.recipeId IN (:ids)` rangée par recette (elle ne coûte rien de plus) et le graphe des conversions se lit sur l'union des ingrédients (toujours une lecture) ; `convertible` d'un composant = toutes ses lignes. **Sans composant : exactement les trois requêtes d'aujourd'hui.** `#[OA\…]` complet, `make openapi`.
7. **Docs** (même commit) : `docs/api/openapi.json`, ADR 0040 (amendements éventuels), `docs/recipes/roadmap.md` (case cochée), skill `repas-dev` Definition of Done (une ligne : « une recette enregistrée n'écrit ses composants que si `Recipe::areComponentsChanged()` ; un modèle chargé sans les lire ne les efface jamais »).

# Expérience de seuil du rapprochement

Légende. Normalisations : N0 = slug actuel (casse, accents, ponctuation) ; N1 = N0 + pluriels repliés ; N2 = N1 + mots vides retirés. Garde-fous sur les mots du nom : G0 = aucun ; G1 = même nombre de mots ; G2 = G1 + mots identiques ou Jaro-Winkler >= 0,88 (identiques si 3 lettres ou moins ou s'ils contiennent un chiffre) ; G3 = idem à 0,90 et 4 lettres ; G4 = G1 + chaque mot est identique ou à une faute près (distance d'édition 1, mots de 5 lettres et plus) ; G6 = G4 mais un mot de 4 lettres peut avoir une faute si son pareil en a 5. Marge : un second candidat à moins de 0,02 du premier rend le lien ambigu (aucun lien).
